# ☁️ CLOUDCOSTIQ – Multi-Cloud Cost & Resource Optimization Analytics

> A data analytics project focused on understanding cloud spending, resource utilization, and potential cost optimization opportunities across AWS, Azure, and GCP.

---

## 📌 About the Project

CLOUDCOSTIQ is an end-to-end data analytics project built to analyze cloud billing and resource utilization data across **AWS, Microsoft Azure, and Google Cloud Platform (GCP)**.

The main objective is to identify **underutilized resources**, understand cloud spending patterns, estimate potential savings, and provide practical recommendations for cost optimization.

The project follows a complete analytics workflow using **Excel, MySQL, Python, and Power BI**.

---

## 🎯 Problem Statement

Cloud environments can grow quickly as organizations add compute, storage, database, and other resources.

When resource usage is not monitored regularly, organizations may continue paying for resources that are not being fully utilized.

**CLOUDCOSTIQ** addresses this problem by combining billing data with utilization metrics to identify potential optimization opportunities.

---

## 🎯 Project Objectives

- Analyze cloud spending across AWS, Azure, and GCP
- Identify underutilized cloud resources
- Analyze CPU, memory, storage, and network utilization
- Compare costs across providers, services, and departments
- Identify high-cost and low-utilization resources
- Calculate potential cost savings
- Build an interactive Power BI dashboard
- Generate practical business recommendations
